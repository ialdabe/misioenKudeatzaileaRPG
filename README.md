# RPG misioen kudeatzailea — hasierako txantiloia

Web Sistemak irakasgaiko V. laborategiaren eskeletoa.

## Egitura

```
public/
├── index.html   # Interfazea (formularioa, botoiak eta misioen zerrenda)
├── main.js      # Bezeroaren logika (TODO markak eta funtzio hutsak osatu behar dira)
└── style.css    # Estiloak
data/
└── quests.json  # Zerbitzariko misioak (2. fasean erabiliko da)
```

## Nola hasi

1. **1. fasea:** ireki `public/index.html` nabigatzailean eta osatu `public/main.js` fitxategiko funtzioak, `localStorage` erabiliz.
2. **2. fasea:** prestatu Node.js proiektua eta sortu `app.js` fitxategia proiektuaren erroan. Zerbitzaria abiarazi ondoren, ireki aplikazioa zerbitzariaren helbidetik.

Xehetasun guztiak laborategiaren gidoian daude.
